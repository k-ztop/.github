## 한옥을 짓듯이

K-ZTOP은 한옥을 짓는 순서처럼 해마다 한 단계씩 올라갑니다.

| 연차 | 버전 | 이름 | 뜻 |
|---|---|---|---|
| 1차 (2026) | 0.9 Developer Preview | 주춧돌 **Juchudol** | 기둥을 받치는 받침돌. 참조 구현과 표준 API 초안 |
| 2차 (2027) | 1.0 | 기둥 **Gidung** | 뼈대가 서는 단계. 실증과 첫 안정판 |
| 3차 (2028) | 2.0 | 대들보 **Daedeulbo** | 무게를 받치는 핵심 구조. 고도화와 대규모 운영 |
| 4차 (2029) | 3.0 LTS | 용마루 **Yongmaru** | 지붕 꼭대기, 집의 완성. 통합 실증과 장기 지원 |

## 저장소

| 저장소 | 내용 |
|---|---|
| `platform` | 플랫폼 본체: 판단(PDP)·집행(PEP)·정보(PIP)·관리 서버와 콘솔, 설치 스크립트 |
| `spec` | 표준 명세: 판단 API·데이터 모델·이벤트 스키마·변경 제안(RFC) |
| `workspace` | 참여기관 공동 작업 공간: Issues·Discussions·문서 |

> 지금은 공개 전 개발 단계라 저장소가 비공개입니다. 2026년 11월 말 0.9 "Juchudol" 공개와 함께 `platform`·`spec`을 공개합니다. 라이선스는 Apache 2.0입니다.

## 참여하기

- **참여기관**: 조직 멤버로 초대받아 비공개 저장소의 Issues·PR·Discussions에서 함께 작업합니다. 초대를 받으려면 GitHub 계정 이름과 소속을 아래 메일로 보내 주세요. 조직은 2단계 인증을 켠 계정만 받습니다.
- **외부 기관·개발자**: 공개 전에는 메일 [sga-zt-platform@sgacorp.kr](mailto:sga-zt-platform@sgacorp.kr)로 문의해 주세요. 공개 후에는 각 저장소의 Issues와 Discussions로 모입니다.
- **보안 취약점**: 공개 이슈에 올리지 말고 같은 메일로 비공개로 알려 주세요.

기여 방법은 홈페이지의 [기여 안내](https://www.kztop.kr/community/contribute/)에 정리되어 있습니다.
